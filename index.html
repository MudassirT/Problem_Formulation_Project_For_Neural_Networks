PROBLEM FORMULATION & STATE SPACE

One application graph. A precise search problem.

The source graph describes files, functions, models, templates, tests, and their relationships. This lab preserves every source node, edge, community, and metadata attribute, then adds an explicit search interpretation.

  1. Initial state: the selected application node is the agent’s starting focus.
  2. Actions: traverse existing relationships; no shortcuts or synthetic edges are added.
  3. Goal: reach the selected target node.
  4. Costs: editable illustrative effort per relationship. These are not measured runtime or business costs.
  5. Solution: a path minimizing total modeled effort when using UCS or A* with h = 0.

Why A* uses h = 0: this knowledge graph has no proven estimate of remaining business effort. Canvas distance is a layout choice, so it is not used as a cost heuristic.

Direction: the saved source graph is undirected. The source → target mode is an optional teaching overlay based on stored endpoint order; it does not recover a directed runtime call graph.

Scope: completeness is relative to the existing graph artifacts. Files excluded from the original extraction are not silently invented. Inferred relationships retain their confidence labels.

Playback: frontier/expanded colors show the selected expansion. Path comparison uses bounded loopless path enumeration and reports when its exploration limit is reached.
